# 裤子类（Pants Asset）

Pants 由 `ItemPantsAsset` 创建，可由玩家和 Zombie 穿戴。继承 [BagAsset](/items/bag-asset.html)。

- `GUID`
- `Type Pants`
- `Useable Clothing`
- `ID`

没有 Pants 独有字段，请参阅父类属性。

> 上游原文：[Unturned 官方文档](https://docs.smartlydressedgames.com/en/stable/items/pants-asset.html)
