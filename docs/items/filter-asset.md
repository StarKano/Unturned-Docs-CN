# 过滤器类（Filter Asset）

Filter（辐射过滤器）由 `ItemFilterAsset` 创建，用于恢复防辐射 [Mask](/items/mask-asset.html) 的 Quality。继承 ItemAsset。

- `GUID`
- `Type Filter`
- `Useable Filter`
- `ID`

没有独有字段。

> 上游原文：[Unturned 官方文档](https://docs.smartlydressedgames.com/en/stable/items/filter-asset.html)
