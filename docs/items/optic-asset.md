# 光学设备类（Optic Asset）

Optic 由 `ItemOpticAsset` 创建，可以修改玩家视野。继承 [ItemAsset](/items/introduction.html)。

必需/推荐字段：

- `GUID`：唯一 GUID。
- `Type Optic`
- `Useable Optic`
- `ID` `uint16`：唯一 Legacy ID。

## 专属属性

- **`Zoom`** `float`：缩放倍率，默认 `1`。
