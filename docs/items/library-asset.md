# 经验存储类（Library Asset）

Library 由 `ItemLibraryAsset` 创建，是可放置的 Experience Point Storage。继承 [BarricadeAsset](/items/barricade-asset.html)。

- `GUID`
- `Type Library`
- `Useable Barricade`
- `Build Library`
- `ID`

## 专属属性

- **`Capacity`** `uint32`：最多存储多少 Experience。
- **`Tax`** `byte`：存入时收取的百分比税率，默认 0。
