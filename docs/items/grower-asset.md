# 生长促进剂类（Grower Asset）

Grower（Growth Supplement）由 `ItemGrowerAsset` 创建，可立即完成 [Farm Plant](/items/farm-asset.html) 的生长。继承 ItemAsset。

- `GUID`
- `Type Grower`
- `Useable Grower`
- `ID`

没有独有字段。
