# 降落伞资源（Cloud Asset）

Cloud（本地化通常称“降落伞”）由 `ItemCloudAsset` 创建。玩家手持时可影响重力。继承 [ItemAsset](/items/introduction.html)。

- `GUID`
- `Type Cloud`
- `Useable Cloud`
- `ID`

## 专属属性

- **`Gravity`** `float`：重力影响倍率。
