# 饮品类（Water Asset）

Drink 由 `ItemWaterAsset` 创建，使用后会被玩家消耗，并直接修改 Water、Stamina 等状态。继承 [ConsumeableAsset](/items/consumeable-asset.html)。

- `GUID`
- `Type Water`
- `Useable Consumeable`
- `ID`

没有独有字段，请参阅父类属性。

> 上游原文：[Unturned 官方文档](https://docs.smartlydressedgames.com/en/stable/items/water-asset.html)
