# 容器服装基类（Bag Asset）

`ItemBagAsset` 是其他服装类继承的 Base Class，本身不可直接使用。它继承 [ItemClothingAsset](/items/clothing-asset.html)。

## 属性

| 字段 | 类型 | 默认值 |
| --- | --- | --- |
| `Height` | uint8 | `0` |
| `Width` | uint8 | `0` |

- **`Height`**：Storage 垂直 Row 数。
- **`Width`**：Storage 水平 Column 数。
