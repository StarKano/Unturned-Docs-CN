# 背心类（Vest Asset）

`ItemVestAsset` 用于 Vest Slot，可由玩家和 Zombie 穿戴并覆盖 Torso。继承 [BagAsset](/items/bag-asset.html)。

- `GUID`
- `ID`
- `Type Vest`
- `Useable Clothing`

没有独有字段。
