# 帽子类（Hat Asset）

`ItemHatAsset` 用于占据 Hat Slot 的 Clothing。玩家和 Zombie 可穿戴，用于覆盖头部。继承 [GearAsset](/items/gear-asset.html)。

必需/推荐：

- `GUID`
- `ID`
- `Type Hat`
- `Useable Clothing`

Hat 没有独有属性，请参阅父类。
