# 载具维修工具资源

Vehicle Repair Tool（本地化为“Tool”）由 `ItemVehicleRepairTool` 创建，用于更换 Vehicle Battery。继承 [ToolAsset](/items/tool-asset.html)。

- `GUID`
- `Type Vehicle_Repair_Tool`
- `Useable Battery_Vehicle`
- `ID`

没有独有字段。
