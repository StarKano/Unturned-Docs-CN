# 医疗用品资源（Medical Asset）

Medical Item 由 `ItemMedicalAsset` 创建，使用后不可逆地被消耗，并直接修改 Health、Immunity 等玩家状态。继承 [ConsumeableAsset](/items/consumeable-asset.html)。

- `GUID`
- `Type Medical`
- `Useable Consumeable`
- `ID`

没有独有字段。
