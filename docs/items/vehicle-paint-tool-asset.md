# 载具喷漆工具类

由 `ItemVehiclePaintToolAsset` 创建，用于修改 Vehicle Paint Color。继承 [ToolAsset](/items/tool-asset.html)。

- `GUID`
- `Type Vehicle_Paint_Tool`
- `Useable Vehicle_Paint`
- `ID`

## 专属属性

- **`PaintColor`** [Color](/data/color.html)：使用后 Vehicle 颜色替换为该颜色。
