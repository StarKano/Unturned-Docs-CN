# 遥控引爆器类（Detonator Asset）

Detonator / Remote Trigger 由 `ItemDetonatorAsset` 创建，可以引爆[遥控炸药](/items/charge-asset.html)。继承 ItemAsset。

- `GUID`
- `Type Detonator`
- `Useable Detonator`
- `ID`

没有独有字段。
