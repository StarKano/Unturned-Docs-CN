# 合成材料资源（Supply Asset）

Supply 由 `ItemSupplyAsset` 创建，主要作为 Blueprint 合成材料。它们不能手持或装备。继承 ItemAsset。

- `GUID`
- `Type Supply`
- `ID`

没有独有字段。
