# 服务器浏览器策展类

大部分信息参阅[服务器浏览器筛选规则](/servers/server-browser-curation.html)。

- **`Type`**：`ServerCuration`。
- **`Icon`**：与 Web 托管的策展列表不同，Asset 可以在 Asset Bundle 中包含 32×32 `Icon` Texture。
- **`Name`**：如果存在本地化文件，显示名称优先从本地化文件读取，而不是 Asset 文件。

::: note
玩家订阅后该 Asset **不会默认启用**，需要在 Server Browser 的 Curation 菜单中手动开启。
:::
