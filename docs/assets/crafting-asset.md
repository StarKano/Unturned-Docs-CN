# 合成资源（Crafting Asset）

Crafting Asset 用于在 Item Asset 之外定义蓝图。这样可以更方便地整理没有明确“所属物品”的配方，例如一个蓝图有多个输入和多个输出时，就不一定适合放在某一个具体 Item Asset 中。

- **`GUID`**：参阅 [GUID](/data/guid.html)。
- **`Type`**：`SDG.Unturned.CraftingAsset`。

## 属性

使用与 Item 相同的 **`Blueprints`** 属性，但这里**只支持 V2 蓝图格式**。
