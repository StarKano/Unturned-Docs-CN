# EObjectType

`EObjectType` 包含所有 Object 类型。

| 值 | 索引 | 说明 |
| --- | ---: | --- |
| `Large` | 0 | 大型 Object。 |
| `Medium` | 1 | 中型 Object。 |
| `Small` | 2 | 小型 Object。 |
| `NPC` | 3 | NPC Object。 |
| `Decal` | 4 | Decal Object。 |
