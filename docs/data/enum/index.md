# 枚举类型

这里收录 Unturned 文档中使用的枚举（Enum）类型。

枚举用于把一组固定的命名值映射到游戏内部数据，例如物品稀有度、物品类型、光照视觉模式等。

具体枚举请通过左侧“数据”分类进入对应页面。
