# EItemRarity

`EItemRarity` 包含游戏内容可用的稀有度。它与 Steam Economy Item 的 Quality **不是同一概念**。

| 值 | 索引 | 说明 |
| --- | ---: | --- |
| `Common` | 0 | 常见，白色。 |
| `Uncommon` | 1 | 罕见，绿色。 |
| `Rare` | 2 | 稀有，蓝色。 |
| `Epic` | 3 | 史诗，紫色。 |
| `Legendary` | 4 | 传说，粉色。 |
| `Mythical` | 5 | 神话，红色。 |
