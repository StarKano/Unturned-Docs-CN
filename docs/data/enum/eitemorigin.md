# EItemOrigin

`EItemOrigin` 用于指定生成 Item 的来源，并影响物品初始状态。

| 值 | 说明 |
| --- | --- |
| `World` | 来源于世界生成。 |
| `Admin` | 来源于管理员命令。 |
| `Craft` | 来源于合成。 |
| `Nature` | 来源于自然/环境。 |

> 上游原文：[Unturned 官方文档](https://docs.smartlydressedgames.com/en/stable/data/enum/eitemorigin.html)
