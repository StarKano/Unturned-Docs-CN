# EBatteryMode

`EBatteryMode` 决定 Vehicle Battery 在某种状态下如何变化，仅用于 [Vehicle Asset](/assets/vehicle-asset.html)。

| 值 | 说明 |
| --- | --- |
| `None` | 电量保持不变。 |
| `Burn` | 电量随时间减少。 |
| `Charge` | 电量随时间恢复。 |

> 上游原文：[Unturned 官方文档](https://docs.smartlydressedgames.com/en/stable/data/enum/ebatterymode.html)
