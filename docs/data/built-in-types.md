# C# 内置类型

| C# 类型 | 别名 | 范围 | 默认值 |
| --- | --- | --- | --- |
| `bool` | Boolean | `true` / `false` | `false` |
| `int8` | sbyte | `-128` 到 `127` | `0` |
| `uint8` | byte | `0` 到 `255` | `0` |
| `int16` | short | `-32768` 到 `32767` | `0` |
| `uint16` | ushort | `0` 到 `65535` | `0` |
| `float32` | float, single | 约 7 位有效数字 | `0` |
| `int32` | int | `-2147483648` 到 `2147483647` | `0` |
| `uint32` | uint | `0` 到 `4294967295` | `0` |
| `float64` | double | 约 15 位有效数字 | `0` |
| `int64` | long | `-9223372036854775808` 到 `9223372036854775807` | `0` |
| `uint64` | ulong | `0` 到 `18446744073709551615` | `0` |
| `string` | — | 0 个或更多 Unicode 字符 | `null` |

更多信息见 Microsoft [Built-in types (C# reference)](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/built-in-types)。
