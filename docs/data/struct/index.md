# 结构体

这里收录 Unturned 文档中使用的结构体（Struct）类型。

结构体通常由多个相关字段组成，用于表达一组配置数据，例如颜色、位置、灯光参数或复杂资源属性。

具体结构体请通过左侧“数据”分类进入对应页面。
