# 服务器更新通知

Unturned 的更新日志可以在 Steam News Hub 查看。

如果只希望快速获得 **游戏版本号** 和 **Steam Build ID**，官方提供了以下两种方式。

## Discord

Unturned 官方 Discord 的 `#dedicated-server-updates` 频道会通过 Webhook 发布专用服务器更新通知。

每条通知包含游戏版本号和 Steam Build ID。

## RSS

Smartly Dressed Games 提供专用服务器更新 RSS：

```text
https://smartlydressedgames.com/rss/unturned-steam-dedicated-server-updates.xml
```

可以把这个 RSS 接入自己的监控程序、机器人或自动运维系统。
