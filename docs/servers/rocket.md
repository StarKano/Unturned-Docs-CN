# Rocket / LDM

Smartly Dressed Games 维护了 Rocket 的一个分支，名称为 **Legally Distinct Missile（LDM）**。

官方更推荐使用这个维护版，因为它继续兼容 Rocket 生态，并修复了旧 Rocket 中的一些重要问题，例如多线程异常和传送相关漏洞。

## 安装

U3DS 已经包含最新版本，不需要额外下载。

1. 在游戏安装目录的 `Extras` 中找到 `Rocket.Unturned` 模块。
2. 将其复制到游戏目录的 `Modules` 文件夹。
3. 启动服务器。

## 历史

Rocket 原社区维护团队于 2019 年停止维护，并以 MIT License 发布源代码。

之后 SDG Fork 了项目继续维护，并在 2020 年根据原作者要求重新命名，以与原 Rocket 项目区分。
